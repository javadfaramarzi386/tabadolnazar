# 💬 تبادل نظر

یک پلتفرم انجمن گفت‌وگو (Forum) ساخته‌شده با **Python و Django** که کاربران می‌توانند در آن موضوع ایجاد کنند، درباره موضوعات مختلف گفتگو کنند و با یکدیگر تعامل داشته باشند.

این پروژه با هدف یادگیری عملی و عمیق‌تر توسعه وب، طراحی و توسعه یک پروژه واقعی و آشنایی با فرآیند توسعه نرم‌افزار ایجاد شده است.

## 🚀 نصب و اجرای پروژه

### ۱. دریافت پروژه

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
```

### ۲. ساخت محیط مجازی

```bash
python -m venv venv
```

### ۳. فعال‌سازی محیط مجازی در Windows

```bash
venv\Scripts\activate
```

### ۴. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### ۵. تنظیم متغیرهای محیطی

یک فایل `.env` در ریشه پروژه ایجاد کنید و متغیرهای موردنیاز را در آن قرار دهید.

نمونه:

```env
SECRET_KEY=your-secret-key
DEBUG=True

DB_NAME=your_database_name
DB_USER=your_database_user
DB_PASSWORD=your_database_password
DB_HOST=localhost
DB_PORT=5432
```

> ⚠️ فایل `.env` شامل اطلاعات حساس است و نباید در GitHub قرار گیرد.

### ۶. اجرای Migrationها

```bash
python manage.py migrate
```

### ۷. ساخت کاربر مدیر

```bash
python manage.py createsuperuser
```

### ۸. اجرای سرور توسعه

```bash
python manage.py runserver
```

سپس پروژه را در آدرس زیر باز کنید:

```text
http://127.0.0.1:8000/
```
